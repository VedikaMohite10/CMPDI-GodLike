# CMPDI/CIL Mining Intelligence Platform

Phase 1 foundation scaffold for the SIH prototype.

## Included
- Vite + React + JavaScript
- React Router configured for placeholder routes
- Page folders and mock data structure file for future development
- Minimal placeholder pages with headings only

## Run locally
```bash
npm install
npm run dev
```

This phase intentionally includes no styling, shell, navigation, or feature logic beyond the route skeleton.
